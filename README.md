# 💼 Portfolio v2

A personal developer portfolio website built with React, showcasing projects, skills, and contact information.

🔗 **Live Demo:** [viktoriia-code.github.io/portfolio-v2](https://viktoriia-code.github.io/portfolio-v2/)


## ✨ Features

- Responsive design optimized for all screen sizes
- Project showcase section
- Skills & technologies overview
- About me section
- Contact information
- Deployed via GitHub Pages


## 🛠️ Tech Stack

- **React** — UI library
- **JavaScript** — primary language
- **HTML/CSS** — markup and styling
- **GitHub Pages** — deployment


## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Viktoriia-code/portfolio-v2.git
   cd portfolio-v2
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

   The app will open at [http://localhost:3000](http://localhost:3000).


## 📦 Deployment

This project is deployed automatically to GitHub Pages. To deploy manually:

```bash
npm run deploy
```
